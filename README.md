# Ángeles & Agustín — Couple Idea

Una experiencia web interactiva y responsive para celebrar nuestra historia desde el 8 de octubre de 2025.

## Stack
- React + Vite
- CSS moderno, animaciones nativas y diseño mobile-first
- Sin backend obligatorio

## Experiencia
- Contador de tiempo juntos en vivo
- Hero cinematográfico
- Galería inmersiva
- Timeline de recuerdos
- Polaroids interactivas
- Recuerdo aleatorio
- Modo aniversario automático cada 8 de octubre
- Detalles especiales el día 8 de cada mes
- PWA instalable

## Desarrollo
```bash
npm install
npm run dev
```
